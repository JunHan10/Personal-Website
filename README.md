# Personal Website - Jun Han

A modern, responsive personal website showcasing my skills, experience, and interests.

## Features

- Responsive design that works on all devices
- Dark wooden color scheme
- Smooth scrolling navigation
- Animated sections
- Interactive skill and hobby cards
- Contact information and social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome Icons

## Setup

1. Clone the repository
2. Open `index.html` in your web browser
3. No additional setup required

## Customization

To customize the website:

1. Replace the placeholder profile image in the About section
2. Update the contact information in the Contact section
3. Add your social media links
4. Modify the color scheme in `styles.css` by changing the CSS variables in the `:root` selector
